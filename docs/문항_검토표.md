| 점수 | 선택지 | 피드백 |
|---|---|---|
| +10 | 기기번호·증상·발생 시각을 정리해 정보 담당 선생님께 전달하고 수리 접수(테크센터)를 요청한다 | 관찰→기록→보고→조치 확인. 맞는 사람에게 정확히 연결했어요. |
| 0 | 다음 시간에 또 보고 판단한다 | 이미 2주째예요. 기록이 있으니 지금 연결할 때예요. |
| 0 | 충전함에 그냥 넣어 둔다 | 다음 수업에 이 기기를 받은 학생이 또 멈춰요. |
| −5 | 직접 열어서 고쳐 본다 | 학교 기기를 임의로 분해하면 수리·보증이 어려워져요. |

### 3-2. 15번 충전 — 15번 기기가 충전함에서 충전이 안 돼요.

| 점수 | 선택지 | 피드백 |
|---|---|---|
| +10 | 충전함 칸 번호를 확인해 정보 담당 선생님께 전달하고 행정실(수리·물품)로 연결한다 | 물품·수리는 행정실로. 칸 번호까지 남겨 정확히 연결했어요. |
| +5 | 정보 담당 선생님께 "충전이 안 돼요"라고만 전한다 | 방향은 맞지만 어느 칸인지 몰라 다시 찾아야 해요. |
| 0 | 다른 칸에 꽂고 끝낸다 | 고장 난 칸은 그대로라 다음 기기도 충전이 안 돼요. |
| −5 | 케이블을 집에서 가져온다 | 검증되지 않은 개인 물품은 학교 기기에 쓰지 않아요. |

✏️ 수정:

### 3-3. 9번 학생 — 9번 학생이 손을 들까 말까 망설이다 내렸었어요.

| 점수 | 선택지 | 피드백 |
|---|---|---|
| +10 | 담임 선생님께만 짧게 공유하고, 다음 수업 자리·지원 방법을 협의한다 | 필요한 사람에게만. 다음 수업에서 먼저 살필 수 있어요. |
| 0 | 공유하지 않는다 | 같은 신호가 다음 수업에도 반복될 수 있어요. |
| −5 | 다른 학생들 앞에서 이야기한다 | 학생의 어려움을 공개하면 다음 수업에 더 숨게 돼요. |
| −5 | 반 단톡방에 공유한다 | 학생 정보는 필요한 사람에게만. 단톡방은 공개 지적이 돼요. |

## 4. 마지막 문항 — 다음 수업 전에 꼭 점검할 것 1개는?

4개가 나옴: 기록장 첫 카드와 맞는 항목(+10) · 기본 루틴 · 0점 · −5점. 기록장이 비면 기본 루틴이 +10.

| 점수 | 선택지 |
|---|---|
| +10 (기록장에 「12번 태블릿」 있을 때) | 12번 태블릿 수리 접수가 됐는지 확인한다 |
| +10 (기록장에 「15번 충전」 있을 때) | 충전함 15번 칸 수리 여부를 확인한다 |
| +10 (기록장에 「9번 학생」 있을 때) | 9번 학생 자리·지원 방법을 담임 선생님과 확인한다 |
| +10 (기록장에 「전자칠판 화면」 있을 때) | 전자칠판에 띄울 화면을 선생님과 미리 확인한다 |
| +5 (기록장 비면 +10) | 선생님과 수업 전 5분 루틴(충전·접속·로그인)을 함께 점검한다 |
| 0 | 새로 나온 AI 앱을 먼저 깔아 보고 수업에 쓸지 정한다 |
| −5 | 시간 절약을 위해 학생 기기에 미리 로그인해 둔다 |
